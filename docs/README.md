# Project Documents

Thu muc `docs/` duoc sap xep theo nhom de de quan ly va tranh tron lan giua file nop bai, tai lieu tham khao va script noi bo.

- `reports/`: bao cao tien do, file Word dang chinh sua, script/ghi chu phuc vu nop bao cao, va bo screenshot hien con su dung.
- `thesis/`: luan van, de cuong, va cac file Word tham khao o cap do de tai.
- `technical/`: tai lieu ky thuat, backend/API, va huong dan tich hop he thong.
- `training/`: ghi chu huan luyen model, benchmark, va ke hoach cai tien.
- `tools/`: script noi bo de sinh slide/bao cao. Mot so script o day la script lich su, co the phu thuoc vao artifact ben ngoai repo hoac bo anh cu da duoc don khoi repo.

Quy uoc don dep:

- Artifact tam thoi sinh ra khi render/QA tai lieu khong luu trong repo.
- `docs/node_modules/`, `docs/render_*` va `docs/reports/render_*` da duoc dua vao `.gitignore`.
- Du lieu audio lon nam ngoai `docs/`, trong `data/` va `resources/`.
